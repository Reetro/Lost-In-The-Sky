# Lost in the Sky: context for AI assistants

## What this is
A NeoForge 1.21.1 mod (Java 21), an addon for Create Aeronautics. It raises the overworld to 2,000 blocks tall and adds four layers of floating sky islands, so players have a reason to build airships. It's for Justin's own modpack (details below).

- Mod id: `lost_in_the_sky` · Package: `com.reetro.lostinthesky` · Author: Reetro · License: MIT
- Build setup: ModDevGradle 2.0.144, NeoForge 21.1.248, parchment 2024.11.17.
- Create Aeronautics' internal mod id is `simulated` (not `aeronautics`). It needs `sable`.
- Create Big Cannons (`createbigcannons`) is a required dependency, >= 5.11.7, the first version supporting Sable 2.0. It needs Ritchie's Projectile Library (`ritchiesprojectilelib`, 2.1.2). Both come from CurseForge through Curse Maven (`https://cursemaven.com`), pinned by CurseForge file ID (`cbc_file_id`, `rpl_file_id` in gradle.properties).

## Status
- First version. It was written without access to Minecraft sources, so expect a few small fixes at runtime.
- API calls that were the likeliest to break on 1.21.1 (they compile now, but check them in game):
  - `JigsawPlacement.addPieces(...)` in `world/SkyJigsawStructure.java` (args: DimensionPadding.ZERO, LiquidSettings.APPLY_WATERLOGGING, PoolAliasLookup.EMPTY)
  - `Mob.finalizeSpawn(...)` in `world/SkyIslandFeature.java`
  - `Registry#getHolder`, `registryOrThrow` in `world/SkyWorld.java` (1.21.1 names; 1.21.2+ renamed them)
- Compiles (`./gradlew compileJava`) as of 2026-11-22; not yet run in game.
- `world/IslandMath.java` is pure Java and was tested on its own: no island reaches past the 3x3 cell neighbourhood (3D island shapes, ~178M blocks checked, 2026-11-22). The 3D shapes cost more per block than the old heightmap; worldgen speed not yet measured in game.

## Requirements from Justin
- World height about 2,000 blocks. It's set in `data/minecraft/dimension_type/overworld.json`: min_y -64, height 2064, so the top block is y 1999.
- Four layers:
  1. **lower:** about 100 blocks above the ground under each island (anchor `surface`)
  2. **regular:** about 500 above the overworld (sea level + 500)
  3. **high:** about 800 (sea level + 800)
  4. **final:** about 1,000 (sea level + 1000)
- **Must work with any worldgen, especially Tectonic.** Never replace the chunk generator or noise settings.
- A system for adding custom biomes, bosses and structures to sky islands, data-driven so modpacks can add content with JSON.

## Architecture
- `world/IslandMath`: the sky is split into square cells (`cell_size`), with at most one island per cell, decided by world seed + layer salt + cell coordinates. Islands are 3D, not heightmaps: `IslandMath#column(plan, centerY, x, z)` returns a `Column` whose `solid(y)` says which blocks are island, `surface()` the highest one, and `top`/`bottom` an envelope that bounds every solid block (the `int[] out` overload returns just the envelope, for biomes, shadows and spawn caps). Each island rolls an `IslandMath.Shape` from its seed: 1-4 body lobes (40/30/20/10%; lobe 0 sits on the island centre, so the centre is always land) plus 0-5 small debris lobes near the rim at their own height (down to 0.5x depth below), squash axis/aspect, 2D cubic-noise outline (`cubic`/`cubicFbm`: domain warp, bays up to 0.3-0.6 in, bulges up to `EDGE_WOBBLE` 0.22 out), top from dome to mesa (20% terraced), hills, underside from bowl to spire with lumps, spikes, an optional cliff rim and a thickness (0.4-1x depth). Each lobe it touches gives the column a piece; a block is solid if any piece says so, so lobes merge. 3D Perlin noise (`Column#carveNoise`, cell size 0.12-0.45x the radius) then pushes each piece's top gently and its side wall and underside strongly, differently at every height: overhangs, ledges, holes through the rim, arches, hanging and loose chunks. Strength is `Shape#carve` (0.1 smooth to 0.9 shattered). Max radius is clamped to `cellSize / 1.27`, every lobe stays inside the radius and columns are cut at 1 + `EDGE_WOBBLE`, so a 3x3 cell search always finds every island touching a column; top and bottom are hard-clipped to 1.55x the plan's top height/depth. Bounds checked in a standalone run (40 islands per layer, ~178M blocks): nothing past `reach()` or the 3x3 cells, nothing solid outside the envelope, land at every island centre, top at most 1.5x the layer's `top_height`, underside at most 1.4x its `depth` (callers allow 2x). Caves: see below.
- `world/SkyWorld`: one per server, built lazily from datapack registries and reset on `ServerStoppedEvent`. It resolves and caches islands, and works out the terrain height for `surface` layers from the overworld's own `ChunkGenerator.getBaseHeight` (follows Tectonic). The feature, biome mixin and structure all ask it, so they agree on where islands are.
- No island sits squarely over the layer below it: an island whose centre is closer to an island in the next layer down than `IslandMath.STACK_FACTOR` (0.7) x their combined reach is dropped (`SkyWorld#overlapsLowerIsland` / `IslandMath#stacked`, lower layer wins). Edges may overlap by up to 30%; at 1.0 (no overlap at all) extra islands in one layer just deleted islands in the next. Only the layer directly below is checked. With the default JSON, islands per 1000x1000 blocks (simulated with `IslandMath`, 2026-11-22): lower ~8.0, regular ~6.3, high ~3.8, final ~3.7. Layers two or more apart (e.g. final over lower) can overlap.
- `world/SkyIslandFeature`: a feature added to all `#minecraft:is_overworld` biomes at step `top_layer_modification`, via `neoforge/biome_modifier/add_sky_islands.json`. It only writes its own chunk's 16x16 columns, only fills air, then places decorations and encounters. Columns are filled top down from `Column#solid`; every block with air above it (top surface, ledges, overhangs) gets the biome's top block, then filler, then core. Decorations go on each column's highest block. Encounters are placed by the chunk holding the island centre; templates are capped at 32x32.
- `mixin/ChunkAccessMixin` + `world/SkyBiomeResolver`: `@ModifyVariable` on `ChunkAccess#fillBiomesFromNoise` wraps the BiomeResolver so island blocks get their sky biome. It only applies to chunks at least 1,024 blocks tall, since a chunk doesn't know its dimension.
- `mixin/PlayerRespawnLogicMixin`: players never spawn on islands. It caps the heightmap reads in `PlayerRespawnLogic#getOverworldRespawnPos` to just below the lowest island underside (`SkyWorld#lowestIslandBottomAt`) and rejects any result still in or on an island. That method handles the world spawn, first join and bedless respawns. Beds and respawn anchors placed on islands still work.
- `mixin/ChunkSkyLightSourcesMixin` + `world/IslandShadows`: islands cast no shadow on the ground. Each chunk's `ChunkSkyLightSources` stores the lowest island underside per column (`SkyWorld#lowestIslandBottomAt`), and any edge at or above it doesn't block sky light, so the column's sky light source drops to the real ground. Trade-off: island caves and roofed builds on islands count as open sky. The client can't compute undersides (no seed or generator), so the server sends `network/IslandShadowPayload` on `ChunkWatchEvent.Sent` and the client rebuilds that chunk's sources (`client/IslandShadowsClient`). Not yet tested in game.
- `mixin/ServerLevelMixin`: `/locate biome` finds sky islands. Vanilla `ServerLevel#findClosestBiome3d` only asks the generator's biome source, which never has island biomes, so this also searches the island grid (`SkyWorld#findClosestIsland`, nearest island centre whose sky biome matches, in growing cell rings). Sky-only biomes skip vanilla's slow search; biomes/tags that can also be on the ground run both and the nearer wins. Not yet tested in game.
- Caves: each island rolls `cave_chance` (per layer). Cave islands get `IslandMath.Caves`, built once per island (`SkyWorld#caves`, cached) from the plan + centre Y: **Perlin worms** (3 + r²/1200 worms, +1 half the time; each starts in the middle of the main lobe, walks in 1.5-block steps with its turn rate and pitch from 1D Perlin, is steered back toward the middle past 0.6 of the radius and toward its own depth band, swells and pinches 2.6-4.2 x size blocks radius, 45% fork once), **entrance worms** (1 + worms/2 tries: start on a tunnel node within 0.5 of the radius, climb at 30-50 degrees until clear of the top; kept only if they come out through the top; the only nodes allowed through the 4-block `CAVE_ROOF`) and **density-function chambers** (two octaves of 3D Perlin over `CHAMBER_THRESHOLD`, with 2D-noise rock pillars). Every wall is pushed by a "crag" field (two octaves of trilinear value noise, `IslandMath#value3`, faceted rather than smooth; strength `jag` 0.35-0.6 per island), which makes the walls jagged. Worm nodes are bucketed by 16x16 column for lookup; `Caves#column(x, z)` gives a `CaveColumn` whose `cave(y, top)` says which blocks are hollow. Columns whose top is carved (cave mouths) get no surface decorations. Standalone run (12 islands per layer, 2026-11-23): 18% hollow on lower up to 23% on final, every cave island has mouths on its top (avg 3.8 per lower island, 4.9 regular, 7.2 high, 8.5 final), building caves ~1 ms per island. The old surface shafts (`entranceFrom`) are gone. Because of `ChunkSkyLightSourcesMixin`, island caves get full sky light (no mob spawns by day).
- Mirrored layers (`mirror_ground_biome`, on for `lower`): `SkyWorld#resolve` asks the overworld biome source for the biome at the island centre's terrain height (`Island#groundBiome`; null over `#is_ocean`/`#is_river`/`c:is_underground`, then the sky biome is used). `Island#surfaceBiome()` is what gets painted and what `/locate biome` matches, so `/locate biome lost_in_the_sky:lower_sky_islands` only finds islands over water now. `SkyIslandFeature#groundProfile` copies the top 5 blocks of the ground under each column (skipping trees, plants, snow layers; stone repeats; water/ice = sky biome blocks) onto every top/ledge of the island. `decorateMirrored` runs the biome's vegetal-step placed features with their own modifiers through `IslandPlacement` (a `PlacementContext` whose heightmaps only see that biome's island tops in the chunk), so density and biome filters match the ground. `addSnow` puts snow on any island top whose biome should snow (all layers). Not yet tested in game.
- Sky structures and island shape (`SkyIslandFeature.Foundations`): the feature reads `sky_jigsaw` starts touching the chunk (`StructureManager#forWorldGenRegion` + `startsForStructure`); under each rigid piece the island is filled up to the piece's floor (`minY + groundLevelDelta - 1`) and kept clear up to its top, if the island surface is within 16 blocks; no caves there, no decorations. `SkyJigsawStructure` drops (non-start) pieces whose centre or more than one corner isn't over the island within 16 blocks of the piece's floor. Not yet tested in game.
- Cave biomes (`sky_cave_biome`, lower layer only by default: `minecraft:lush_caves`, `minecraft:dripstone_caves`, weight 1 each): each cave island in a layer with cave biomes picks one (`Island#caveBiome`). `SkyWorld#skyBiomeAt` gives it to biome cells more than `CAVE_BIOME_DEPTH` (4) blocks under the column's surface, so the top keeps the sky biome; `/locate biome` finds them too. `SkyIslandFeature#fillColumn` records cave floors/ceilings/air per column (`CaveSpots`) and `decorateCaves` places the cave biome's configured features there (vanilla `CaveFeatures`: moss patches, clay pools, cave vines, spore blossoms, rooted azalea, dripstone clusters, glow lichen). Not yet tested in game.
- `world/SkyJigsawStructure` (`lost_in_the_sky:sky_jigsaw`): a jigsaw structure with a `layer` field that starts on an island's surface. Optional `island_center` (start only in the chunk holding an island's centre, at that centre), `min_island_radius` and `island_chance` (one fixed roll per island, salted by layer + start pool) keep spread-out structures on the island; use them with a structure set of spacing 1 / separation 0 so every chunk is a candidate. Islands are features, placed after structures, so terrain-following jigsaw pieces (village streets) would land on the ground: `world/SkyStructureContext` is set while a sky structure lays out pieces, `mixin/JigsawPlacerMixin` then takes child heights from the island surface (`getFirstFreeHeight` in `JigsawPlacement$Placer#tryPlacingChildren`), and `mixin/GravityProcessorMixin` snaps blocks of those pieces to the island surface at placement (when a block would drop >24 blocks below its laid-out height). Off the island edge, pieces stay level with the village. Not yet tested in game.
- AI airships, `ship/` (started 2026-11-25): `ship_brain` block, in the mod's creative tab (`ShipBrains#TAB`). No texture yet: the model points at `lost_in_the_sky:block/ship_brain`, so adding `assets/lost_in_the_sky/textures/block/ship_brain.png` is enough. Right-click opens `ShipBrainMenu`/`client/ShipBrainScreen` (plain fills, no texture), only on a physics object (`Sable.HELPER.getContaining(blockEntity) != null`). Orders: **Follow me** (the clicking player; goal is `follow_distance` 4-64 blocks away horizontally, max(4, distance/2) above their feet; hovers if they're gone or on this ship), **Stay here** (brain's world position when clicked), **Off** (brain lets go, thrusters run normally). Buttons go through vanilla `clickMenuButton`, state comes back through `ContainerData`.
  - **The brain adds no force of its own.** It only throttles (0..1) thrusters linked to it, so a ship can't do more than its thrusters allow and falls if they can't hold it up. Linked thrusters idle when the ship is locked with Aeronautics' Physics Staff (`PhysicsLock`, by reflection because `simulated` isn't on the compile classpath) or the brain is off a ship.
  - `ThrustControl` + `mixin/ServerSubLevelMixin` (wraps each `BlockEntitySubLevelActor#sable$physicsTick` in `ServerSubLevel#prePhysicsTick`) + `mixin/QueuedForceGroupMixin` (`applyAndRecordPointForce`, which every Sable propeller ends in: Aeronautics propellers, smart propellers, propeller/gyro bearings, Create encased fans): records each actor's full-power force and moment (ship-local, per second) and scales it by its throttle. "Can move a ship" = a `BlockEntitySubLevelPropellerActor` or any actor seen pushing, so other mods' thrusters count without code.
  - Controller (`ShipBrainBlockEntity#sable$physicsTick`, each physics step): desired velocity toward the goal (0.8/s per block, max 12 b/s), acceleration toward it (1.5/s, max 8 b/s²) minus gravity; level out (up x world up) and, if the thrusters' sideways forces mostly point one way, yaw to face the goal (> 4 blocks away). `ThrustAllocator` (bounded least squares by coordinate descent, warm-started) picks the throttles whose summed force/m and (I⁻¹ torque) x radius of gyration come closest; vertical counts double. Standalone check (2026-11-25, 4 lift + 2 rear props): hover, forward, differential-thrust yaw, pitch trim and saturation all come out right.
  - Linking: wrench (`c:tools/wrench`) on the brain → server sends `network/BrainLinkModePayload` (brain + candidates) → `client/ShipBrainLinkClient` outlines candidates (yellow; blue = linked, white = brain) through walls; wrench-clicking one sends `BrainToggleLinkPayload` (client cancels the click so the wrench doesn't rotate it; the server checks the wrench, reach 10, same ship, candidate or already linked). Wrench-click the brain again or put the wrench away to stop. Holding a wrench draws blue lines from every brain to its links (links sync through the block entity update tag; `ShipBrainBlockEntity.CLIENT_BRAINS`). Up to 64 links, stored as plot positions. Positions are moved out of Sable's plot with `ClientSubLevel#renderPose(partialTick)`.
  - Sable's `Pose3d` etc. are in `sable-companion`, nested in the Sable jar; `build.gradle` extracts it for compiling (`extractSableCompanion`). Don't move ships with `RigidBodyHandle#addLinearAndAngularVelocity`: the ship went through terrain (2026-11-25). The propeller version is not yet tested in game.
- Datapack registries (`data/SkyRegistries`), files in `data/<ns>/lost_in_the_sky/<registry>/`:
  - `sky_layer`: anchor, offset, max_y, y_jitter, cell_size, chance, min/max_radius, top_height, depth, cave_chance, mirror_ground_biome
  - `sky_biome`: layer, biome, weight, top/filler/core block states, filler_depth, decorations (configured features)
  - `sky_encounter`: layer, chance, sky_biomes filter, optional template, y_offset, entities (missing mods are skipped)
  - `sky_cave_biome`: layer, biome, weight, decorations (configured feature, placement floor/ceiling/air, tries, chance)
  - `sky_ore`: layer, block, chance (fraction of underside stone), vein_size (1-27). Ores only go in the biome's core block below the island's centre Y (the hanging underside). Veins come from `IslandMath#oreAt` (one vein at most per 4x4x4 cell, from island seed + position, so they line up across chunks). Defaults get more valuable with height: lower coal/copper/iron/a little gold, regular coal/iron/gold/redstone/lapis/Create zinc (redstone only on regular), high gold/lapis/iron/emerald, final gold/lapis/emerald and diamond (diamond only on final, the top layer). Chances were cut by 10% across the board on 2026-11-22. Missing blocks are skipped.
- Default content: 4 layers, 7 sky biomes, 2 cave biomes (lower layer: lush and dripstone caves), one custom biome per layer so `/locate biome` can find each (`lost_in_the_sky:lower_sky_islands`, `regular_sky_islands`, `high_sky_islands` (cold, snows), `final_sky_islands`; all sky biomes of a layer use its biome and differ only in blocks/decorations), 2 example encounters (vanilla mobs), a `sky_outpost` structure on the regular layer, and plains villages (`sky_village_lower`, `sky_village_regular`: vanilla `minecraft:village/plains/town_centers`, island-centred, islands of radius 60+ / 80+, `island_chance` 0.5: about 2.3 villages per 1000x1000 blocks on the lower layer and 1.8 on the regular (simulated)). Cave chance (raised 2026-11-23): lower 0.8, regular 0.85, high 0.9, final 0.95.

## Known caveats
- Tectonic's `increased_height` option must be **off**, since both mods override the overworld dimension_type. Don't combine with Sky Lands either.
- New worlds only. The tall world means more chunk sections, so more RAM and bigger saves.
- Bosses spawned raw by encounters (e.g. `cataclysm:ignis`) may expect their own arena. Test each one.
